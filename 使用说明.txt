Paper SA — 朋友安装使用说明

一、Windows 10 / 11 首次安装

1. 保存收到的 ZIP，右键选择“全部解压缩”，打开解压后的 paper-sa 文件夹。
   不要在压缩包的预览窗口里直接运行脚本。
2. 双击 install.cmd，保持联网，等待安装完成。
   脚本会下载 uv、独立的 Python 3.12、应用依赖和 Chromium。
   不需要提前安装 Python、Node.js、Git、Office，也不需要管理员权限。
3. 安装成功后自动启动服务，并在浏览器打开 http://127.0.0.1:8765 。
   使用期间请保留命令行窗口；结束使用时在该窗口按 Ctrl+C。
4. 在左下角“模型与设置”中填写自己的模型提供商、模型名称和 API Key，
   保存后测试连接。安装包不附赠模型额度，也不包含发送者的密钥或论文数据。

二、以后如何启动

打开一个新的 PowerShell 或 Windows 终端，输入：

    paper-sa

无需每次重新运行安装脚本。如果提示找不到命令，重开终端再试，
或执行安装完成时显示的 Executable 完整路径。
如果 8765 端口被占用，可运行：

    paper-sa --port 8899

然后使用 http://127.0.0.1:8899 。
127.0.0.1 指各自的电脑；发送者电脑上的页面链接不能代替安装包。

三、能做什么

- PubMed 检索、导入并阅读本地 PDF、手写 Markdown 笔记不需要模型密钥。
- AI 问答、自动总结和多篇论文报告需要可用的模型服务；可能产生 API 费用。
- 本地 Ollama 模型需要自行安装 Ollama 并下载模型，不随安装器自动下载。
- 下载受限全文需要你自己的学校/机构权限，并在专用浏览器中手动登录。
  本工具不绕过付费墙或验证码，不保证所有论文都能自动下载。
- AI 输出和“论文原文”引用请对照 PDF 核验。

四、网络与安装失败

这是联网安装包，不是离线安装包。建议预留约 1 GB 磁盘空间。
首次安装需要能访问 Astral、GitHub、PyPI 和 Playwright 下载服务。
如果下载失败，请保留报错或截图，检查网络/代理后重新运行 install.cmd。
若仅 Chromium 下载失败，其他功能仍可使用；稍后执行：

    paper-sa install-browser

如果被系统或单位安全策略拦截，请核实文件来源并联系管理员；
不要关闭杀毒软件或全局修改脚本执行策略。

五、数据与更新

在“模型与设置”→“工作目录”→“切换工作目录”中，可以输入新路径或
选择最近目录；切换立即生效。每个目录独立保存论文、笔记与模型设置，
不会自动搬迁旧数据，切回原目录即可继续使用原数据。
普通 paper-sa 启动会记住上次选择；明确指定 --data-dir 或 PAPER_SA_HOME 时
以指定路径为准。切换前请保存设置和其他标签页笔记，并等待运行中的任务结束。

论文、笔记和模型设置保存在各自电脑，不随安装包共享。
Windows 默认数据目录为 %LOCALAPPDATA%\paper-sa，也可在设置中查看。
不要把这个数据目录、.local-data、.env、密钥文件或浏览器登录资料发给别人。
更新时先按 Ctrl+C 退出旧程序，解压新版安装包并重新运行 install.cmd。
重新安装不会主动删除论文或笔记；重要数据请在退出程序后另行备份。

六、macOS / Linux

解压完整 ZIP 后，在终端进入包含 install.sh 的目录，执行：

    bash install.sh

安装完成后打开新终端，执行 paper-sa。
Linux 的浏览器可能还需要系统共享库和桌面环境，请参阅 docs/SETUP.md。
macOS/Linux 尚未在对应平台实机验收；Windows 全新机器首次下载流程也仍需实机确认。

详细功能及使用限制：docs/SETUP.md
